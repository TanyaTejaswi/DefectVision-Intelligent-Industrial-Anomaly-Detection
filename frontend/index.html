AI VISION ARCHITECTURE

How DefectVision Operates Without Defect Training Data

Supervised classifiers fail when brand-new defects appear. DefectVision builds a mathematical memory bank of pristine components, flagging any deviation as an anomalous outlier.

1. ResNet-50 Feature Fusion

Extracts intermediate CNN representations from Layer 2 (sub-millimeter spatial resolution for micro-cracks) and Layer 3 (structural component context), fusing them into 1,536-dimensional patch embeddings.

2. PatchCore Memory Bank

Trained strictly on pristine parts (train/good). Subsamples normal patches using greedy coreset selection, maintaining sub-50ms inference latency without heavy retraining.

3. Thermal Distance Heatmap

Nearest-neighbor Euclidean distance scores each spatial patch against normal memory bank vectors. A 2D Gaussian filter (σ=4.0) generates a JET thermal colormap overlay pinpointing the fracture.
